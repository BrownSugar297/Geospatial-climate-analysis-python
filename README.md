# Geospatial-climate-analysis-python
# Bangladesh Climate Data (2024-2025)

This repository contains Python scripts to extract **monthly climate data** (temperature and precipitation) for **Bangladesh divisions** (8 divisions) for the years **2024 and 2025** from ERA5 NetCDF datasets.

The output is a **CSV file** with the following columns:

- `division` – Name of the division  
- `year` – Year (2024 or 2025)  
- `month` – Month (1–12)  
- `mean_t2m_C` – Mean 2m temperature in Celsius  
- `total_precip_mm` – Total monthly precipitation in millimeters  

---

## **Files**

- `produce_bd_division_monthly.py` – Main Python script to process ERA5 NetCDF files and generate CSV  
- `ERA5/` – Folder containing ERA5 NetCDF files (not included due to size)  
- `data/gadm41_BGD_1.shp` – Bangladesh divisions shapefile (not included)  
- `bd_division_monthly_2024_2025.csv` – Output CSV generated by the script  

---

- Python 3.10+  
- Libraries:
  - `xarray`
  - `rioxarray`
  - `geopandas`
  - `pandas`
  - `numpy`
